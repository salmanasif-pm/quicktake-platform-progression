## **SQDIP Web Platform – Requirements for Solution Team**

### **Objective**

Develop a customizable, web-based SQDIP (Safety, Quality, Delivery, Inventory/Production Schedule, People) monitoring and analysis tool for multi-plant operations, replacing manual/paper processes and allowing site-specific configurations.

---

### **Core Functional Modules**

#### **1. Safety (S)**

- **Display:** Calendar month view with daily status color coding:
  - **Red** – Any safety incident occurred.
  - **Green** – No incidents.
  - **Black** – Not running.
- **Scope:** Plant → Production Area (e.g., Tank Line 1, Tank Line 2, Hoses, Systems).
- **Incident Categories (Dropdown Selections):**
  - Recordable
    - Sprain/Strain
    - Laceration
    - Heat Related
    - Puncture
    - Forklift
    - Trip
    - Fall
    - Other
  - Near Miss (Y/N)
    - Same subcategories as above.
  - First Aid
    - Same subcategories as above.
- **If Incident Occurs (Dropdown Triggered):**
  - Date Discovered – Date field.
  - Problem – Open text.
  - Short Term Solution – Open text.
  - Long Term Solution – Open text.
  - Due Date – Date field.
  - Responsible – 2-letter initials (caps) of first and last name.

---

#### **2. Quality (Q)**

- **Display:** Bar/line graph per day.
  - **Line:** Goal threshold (e.g., 15 DPU).
  - **Bars:** Actual defects per unit by day.
  - **Color Logic:** Below line = Green; Above line = Red.
- **Scope:** Tank Line 1, Tank Line 2, Hoses, Systems.
- **Root Cause Tracking:** “Reason 1,” “Reason 2,” etc.
- **If Threshold Exceeded:** Trigger same incident workflow as Safety module.

---

#### **3. Delivery (D)**

- **Display:** Bar/line graph per day.
  - **Line:** Goal threshold (e.g., 98% on-time delivery).
  - **Bars:** On-time % by day.
  - **Color Logic:** Below line = Red; Above line = Green; Not running = Black.
- **Scope:** Tank Line 1, Tank Line 2, Hoses, Systems.
- **Root Cause Tracking:** “Reason 1,” “Reason 2,” etc.
- **If Threshold Missed:** Trigger same incident workflow as Safety module.

---

#### **4. Production Schedule (P – Production)**

- **Display:** Bar/line graph per day.
  - **Line:** Goal threshold (e.g., 95% schedule completion).
  - **Bars:** Completion % by day.
  - **Color Logic:** Below line = Red; Above line = Green; Not running = Black.
- **Scope:** Tank Line 1, Tank Line 2, Hoses, Systems.
- **Root Cause Tracking:** “Reason 1,” “Reason 2,” etc.
- **If Threshold Missed:** Trigger same incident workflow as Safety module.

---

#### **5. People (P – People/Morale)**

- **Logic:**
  - No call-offs/no-shows (0) = Green.
  - 0 call-offs/no-shows = Red.
- **No reason codes or incident workflow for now.**

---

### **General Functional Requirements**

- **Multi-Level Scope:** Plant → Production Area → System Type.
- **Customizable Thresholds:** Each metric’s goal to be adjustable per site/line.
- **Role-Based Access:**
  - Admin: Full control over plants, metrics, and thresholds.
  - Supervisor: Edit and approve incidents for assigned areas.
  - Operator: Data entry only.
- **Data Entry:**
  - Manual entry for facilities without automated systems.
  - Future-proofing for integration with ERP/WMS/BI tools.
- **Reporting & Analysis:**
  - Real-time dashboards with color-coded status indicators.
  - Drill-down capability into incident details.
  - Exportable reports for management review.
- **Historical Data:** Retain historical records for analysis and trend tracking.

---

### **Technical Priorities for MVP**

- Implement **Safety** and **Quality** modules with full workflows.
- Basic user management and role-based permissions.
- Dashboard with plant/line views and color-coded daily status.
- Manual data entry forms and CSV export.
- Configurable goals per metric and per line.
