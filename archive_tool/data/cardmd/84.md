## Description

### **Immediate Requirements (MVP)**

Let’s use V0 for Frontend as client has very limited budget

1. **Landing Page / Web App**
   - Simple quote request form (like [http://Hotels.com](http://Hotels.com "smartCard-inline")  for internet service).
   - Fields: name, email, phone (business + cell), physical address, speed requirement, contract term (1/2/3 years with radio buttons), router option (yes/no).
   - Lead capture database (store submitted requests).
   - Ability to later reference past requests in the system.
   - Should work on **desktop + mobile**.
2. **Address Lookup & Mapping**
   - Capture the **physical address** input by users.
   - Show location on Google Maps / pull image from Google.
3. **Communications**
   - SMS/chat button for prospects who hesitate to fill the form.
   - Integration with Twilio (or similar) for SMS.
   - Initially SMS goes directly to David’s number (future: chatbot/AI).
