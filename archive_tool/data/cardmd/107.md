## Description

**Goal:**
Build a **web-based fleet management dashboard (SkyConnect)** that displays all operational data for air-tour operators.

**Core MVP Requirements:**

- Dashboard showing:
  - Fleet status (active / grounded / maintenance)
  - Pilot & crew availability
  - Bookings summary
  - Revenue projections
  - Route pricing (simulated)
  - Weather info (simulated)
  - Flight restrictions/TFR alerts (simulated)
  - Maintenance alerts & readiness indicators

**Data Inputs (MVP):**

- Dummy Excel/CSV data
- Dummy Google Calendar–style data

**Users:**

- Only top-level executives (CEO/COO/CFO/President)
- Full dashboard access

**Platform:**

- Web application
- Login/authentication
- Simple dashboard UI
