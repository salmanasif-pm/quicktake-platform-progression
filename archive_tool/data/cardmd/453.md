## Description

Create an estimate for Student Pathways AI, a pilot platform meant to solve the fragmented high school-to-college/trade school planning process by giving students one secure place to create a profile, receive an AI-generated roadmap by grade/semester, track required actions, access key resources like counselors/tutors/mentors/test prep/financial aid/colleges/trade schools/internships, and get reminders when actions are incomplete. Please scope the MVP around student login, intake form, AI roadmap generation, dashboard/action tracking, resource hub, alerts, basic reporting, and student-data security/compliance considerations.
