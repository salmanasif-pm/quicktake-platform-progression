## Description

- **Users & Structure**
  - ~300–350 companies grouped into ~20–40 cohorts.
  - Each company has its **own dashboard**.
  - Admin (Greg) needs **industry-wide dashboard** aggregating all data.
- **Core Functions**
  - Companies **input financial & operational data** (manual entry form).
  - System **stores targets + actuals** → auto-calculates performance/variance.
  - Aggregates company data → **summary + ranking view** for fast review.
  - Allow **different targets per company** (editable by admin).
  - Admin can **add or remove KPIs** dynamically later.
- **Metrics (initial)**
  - Sales: leads, estimates, closed deals.
  - Finance: gross profit, direct cost, indirect cost, overhead.
  - HR: retention, turnover.
- **Dashboards**
  - Company-level dashboards (individual).
  - Global dashboard (aggregate view of all companies).
  - Optional: group-level aggregation (future phase).
- **Tech Requirements**
  - Host on client’s **GoDaddy-based site** (confirm backend compatibility).
