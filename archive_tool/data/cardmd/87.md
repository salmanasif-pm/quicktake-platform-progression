## Description

**Platform Need**

- Build a **custom AI software** (dashboard + chat) that integrates multiple AI tools Marimo currently uses.
- Purpose: avoid dispersion from switching between different platforms; one place to manage all.

**Users**

- ~35–40 employees.

**AI Stack to Integrate**

- **Gemini (Google Workspace)** → research, analysis.
- **Nextatlas** → trend prediction.
- **MidJourney** → still image generation (paid subscription).
- **Kling** → video generation (paid subscription).
- **“VO3” (Google Workspace)** → video (exact name to confirm).
- **NanoBanana (in Gemini)** → image editing/modification.

**Core Functions (as discussed)**

- **Single Chat Interface** or **Dashboard** to:
  - Do research (Gemini).
  - Run trend analysis (Nextatlas).
  - Generate creative ideas and copy.
  - Produce/modify images (MidJourney, NanoBanana).
  - Generate video (Kling, VO3).
- Each user can log in and manage their own tasks/answers.
