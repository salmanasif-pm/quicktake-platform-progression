## Description

The client currently manages two separate legacy platforms for sports betting and lottery (Tombola) operations. Both systems lack modern architecture, are inefficient in performance, and offer poor user experiences on mobile and desktop. Reporting, transaction management, and user permissions are cumbersome and prone to errors. The client needs a modernized web-based and mobile-optimized solution built on .NET 8/9, using [http://ASP.NET](http://ASP.NET "smartCard-inline")  MVC, Entity Framework 6, and Bootstrap responsive design, with advanced features like real-time updates via AJAX, integrated reporting (PDF/Excel), secure APIs, and seamless user management to scale operations efficiently.
