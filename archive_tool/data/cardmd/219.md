## Description

The prospect is looking for a mobile application (hybrid) through which they want to monetize their business and it should have below features:

- It is primarily a B2C application.
- Should be able to track symptoms.
- Educational resources like blogs, webinars are accessible.
- Tech integration like wearable tech, fitbit, google fit, apple watch etc.
- Access to healthcare professionals in their marketplace.
- Have Community support in it.
- Accountability Program.
- Gamification Element like badges, points etc.
- Should be HIPAA compliant and GDPR compliant for security and privacy.
- Should have reporting and data analysis for each user role.
