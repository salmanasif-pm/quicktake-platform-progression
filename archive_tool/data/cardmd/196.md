## Description

Prospect needs to make a mobile application that will allow sales to generate and input leads into database. The mobile application has to be native.

They’re are trying to have it developed in phases and this is phase 1, so please make sure to have it as simple as possible and to keep the estimated days realistic.

The key outcomes of this mobile application will be:

1. Be able to create lead record given the required fields.

1. Be able to scan QR and automatically map the details into relevant fields then save the record into the DB, and can display it into the full web application when accessed.

1. Be able to list leads and view their detailed page as needed.
2. Be able to edit stages and types.

They’ve already developed figma design so we don’t need to worry about that part.
