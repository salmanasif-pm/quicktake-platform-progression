## Description

The goal is to design and implement a robust, scalable system for managing patient data with two linked databases:

1. **Primary Patient Database**: A repository for individual patient data that can be easily searched and updated.
2. **Secondary Analytical Database**: A dynamic log of patient health information for trend analysis and decision-making.

The system will replace the current manual Excel-based processes with an automated, AI-driven approach for improved efficiency and accuracy.
