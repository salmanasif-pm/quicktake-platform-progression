## Description

### **Project Overview**

Leo runs an ESL learning program hosted on LearnWorlds with **16,000+ students**. The course is structured into **60 steps**, combining grammar, repetition, and vocabulary lessons, with optional live sessions on Zoom.

He wants to elevate engagement and learning outcomes by introducing an **AI tutor** and **gamified learning module** — ideally integrated within LearnWorlds or running in parallel without disrupting the user flow.

---

### **Key Requirements**

#### **1. AI Tutor**

- Acts as a **virtual teacher** to replace or complement live instructors.
- Must have **memory of each student’s progress** (context retention).
- Should use **voice interaction** (not just chat).
- Voice avatar powered by **11Labs**, [http://Murph.ai](http://Murph.ai "smartCard-inline") , or similar TTS/voice synthesis tools.
- Capable of **pronunciation correction**, **contextual feedback**, and **lesson-based dialogue**.
- Integrates seamlessly with LearnWorlds lessons, ideally embeddable.

#### **2. Gamified Learning**

- Lightweight learning games (Duolingo-style):
  - Word match
  - Sentence builder
  - Fill-in-the-blank / quiz
  - XP and progress-based rewards
- Should boost engagement without affecting course flow.
- Must be **developable within 3–4 weeks** for MVP.

---

### **Integration Considerations**

- Explore **LearnWorlds API capabilities** (embedding, data sync, progress tracking).
- If direct integration isn’t possible, propose a **parallel web or mobile app** that syncs course progress and user credentials.
- Maintain LearnWorlds as the **main learning platform** and payment system.
