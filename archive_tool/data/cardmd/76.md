**📌 Client Pain Points**

- Universities struggle to integrate AI tools directly into Moodle due to plugin/API limitations.
- Faculty, students, and instructional designers have disconnected experiences with AI tools.
- Data from LMS, SIS, and Admissions systems is siloed, making analytics and CRM integration difficult.

**📌 Client Requirements**

- Build and deploy **3 AI Agents** (Instructional Designer, Faculty, Student) with **separate cost estimates** for each.
- Create a **custom Moodle plugin** to expose course content, faculty-course mapping, and grading rubrics to backend.
- Implement **SSO (Google/Microsoft)** with domain-based access control.
- Deploy **cloud instances (one per school)** with secure environment configuration (GCP/AWS/Azure).
- Cloud deployment includes:
  - Configuring environment variables (SSO keys, plugin token, Gemini API keys, DB keys)
  - Hosting all agents in secure, isolated environments
- Centralize LMS/SIS data to CRM/OPM environment (Salesforce confirmed for MVP).
