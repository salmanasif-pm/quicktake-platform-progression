## Description

The architectural firm needs a custom automated project checklist system to streamline workflow, reduce human error, and enforce contract approvals before project start. Key requirements include task assignment, milestone tracking, automated reminders, role-based access, integration with CMAP and optionally Autodesk tools, dashboard reporting, proposal/pricing support, and an audit trail for accountability. The goal is to standardize processes across studios, improve consistency, save time, and allow project managers and directors to monitor progress and approvals in real-time without disrupting current design workflows.
