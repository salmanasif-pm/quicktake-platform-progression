## Description

**1️⃣ Client Pain Point**

- Current platforms (Lightspeed, Teachable) take a percentage of sales and are not fully customized for the client’s needs.
- Client wants a **trusted, mobile-accessible source** for patient safety content that patients/families can use in real time (e.g., ICU, stroke, burns).
- Needs **ownership of the platform** to avoid long-term revenue sharing.
- Must be **cost-effective** for a proof of concept, but scalable for future growth (more features like medication tracking, games, etc.).

---

**2️⃣ Client Requirement**

- **Phase 1 (POC):**
  - Searchable knowledge base of existing content (courses, scripts, articles).
  - **Tiered Access**: Free (basic content) and Paid (full access).
  - Admin panel to allow the client to **update content without developer help**.
  - **Mobile-first** solution installable on phones.
  - Minimal cost/time to validate concept with TikTok audience and pilot hospitals.

---

**3️⃣ Suggestion (Proposed Approach)**

- **Platform:** Build as a **Progressive Web App (PWA)** for fast release and mobile installability without App Store delays.
- **Frontend:**
  - Use **v0 Agent** to generate React + Tailwind CSS UI for speed.
  - Keeps frontend build lean, focusing on core screens (login, dashboard, search, content view).
- **Backend:**
  - Use **Firebase** (Auth, Firestore, Storage, Functions) to minimize backend engineering.
  - Engineer focuses on backend logic (Firestore rules, payment integration with Stripe, admin panel configuration).
- **Goal:** Keep development scope **as limited as possible** for a POC while ensuring it can scale to full app later.
