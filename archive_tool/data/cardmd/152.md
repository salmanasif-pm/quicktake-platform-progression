## Description

### Objective

Develop a **web-based onboarding platform** to automate the customer data collection and KYC process for BlackCapital. The goal is to replace a current manual/JotForm-based process with a secure, scalable digital workflow.

---

### Core Use Case

BlackCapital is onboarding thousands of users (B2B model) at once—primarily foreign visa workers (H-2A/H-2B), undocumented immigrants, and unbanked U.S. citizens. Currently done manually by agents. They want to:

- Eliminate human involvement from the onboarding flow.
- Enable onboarding via a public web form or QR code.
- Automatically route data through background checks and card issuance systems.

---

### Key Features & Functional Requirements

#### 1. **Web-Based Onboarding Portal**

- Branded form (e.g. `blackpay.com/onboarding`) accessible via direct URL or QR code.
- Mobile-first responsive design.
- Multi-language support (EN + ES optional for future).

#### 2. **Data Fields to Capture**

- First Name
- Last Name
- Phone Number (U.S.)
- U.S. Address
- Passport photo (upload)
- Domestic ID photo (upload) — optional: driver's license, etc.
- Selfie / Live face photo (upload)
- Social Security Number or ITIN (optional for U.S. citizens only)

> **Note**: Fields may vary slightly based on user type (visa-holder vs U.S. citizen)

#### 3. **Document Capture & Validation**

- OCR extraction for name/DOB/ID number from uploaded docs
- Image quality validation (e.g. blur detection)
- Face matching (passport vs selfie) – Optional in MVP
- Save all images securely for back-end review

#### 4. **Automated Background Check (KYC)**

- API integration with **LexisNexis** for blacklist verification:
  - OFAC screening
  - Global AML lists
  - Identity validation
- Trigger LexisNexis check upon form submission
- Return status: pass/fail + reason (to be saved)

#### 5. **Back-End Dashboard (Optional in MVP)**

- Simple interface to view onboarding submissions
- Export data manually (CSV / JSON)
- Admin status logs (LexisNexis result, time submitted, etc.)

#### 6. **Integration Endpoint for Protek**

- Post-approved onboarding data to Protek system via secure API or SFTP (manual export is OK for MVP)
- Protek handles card printing/shipping
