## Description

**Client Need:**
Native Mobile App for iOS & Android for clients who wants to put in a Personal Injury Cases for Howard.

**User Roles:**

- Admin
- Moderator
- End User

End User can download app free from App store. And does not have to Sign Up to review the Static information.
Now, if the User needs to file a Case request. They can then Sign Up and then get to the portal where they can write their Case in text, upload Image/video/doc.

A Moderator’s role is not clear right now but will be needed as the App grows, so better to have a User Role designed from start.

The backend will be integrated with the existing website’s backend.

**User Flow:**
User Downloads App → No SignUp required → Sees Information Page on App → If User needs to put in their Case details  → User Signs Up → Fill in Case Details.
