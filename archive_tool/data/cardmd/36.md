## Description

The project involves developing a **new version of the existing scanning web application** and integrating it with **Pick-to-Light (PTL) modules** for inventory and order processing. The system will:

- **Scan barcodes**, match SKUs with WooCommerce, and track inventory.
- **Display scanned items and order details** across multiple screens.
- **Integrate with PTL modules**, dynamically assigning scanned products to light-guided storage locations.
- **Automate SKU assignments**, track storage, and synchronize with WooCommerce for inventory updates.
- **Support barcode reassignments, reports, and admin functionalities** like inventory management and data analytics.
- **Handle error scenarios gracefully**, ensuring uptime, cloud backup, and future expansion possibilities.
