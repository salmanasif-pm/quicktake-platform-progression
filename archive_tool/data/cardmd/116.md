## Description

Keebeck is a wealth management firm serving ultra-high-net-worth clients struggling with a fragmented tech stack. Clients must log into multiple platforms,  Moxo (communication), Tamarack (portfolio reporting), and Arch (alternative investments), creating a disjointed experience.

The ask is a custom client portal that unifies all three into a single login. Tamarack can expose data via API but won't ingest external data, so a separate interface layer is the approach. Tamarack and Addepar are contractually locked in for 5 years, so replacement is off the table.
