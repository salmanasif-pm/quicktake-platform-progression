## Description

The Reboot Scholars Yearbook project involves designing and developing a WordPress-based platform to showcase graduate profiles with interactive features and backend management. The scope includes implementing the front-end UI based on approved mockups, enabling modal popups, A-Z filtering, and micro-interactions (scroll effects, button and form animations). On the backend, we will set up a Custom Post Type (CPT) for graduate records with custom fields for text, images, and links, along with a search function. Social media sharing functionality will also be integrated.
