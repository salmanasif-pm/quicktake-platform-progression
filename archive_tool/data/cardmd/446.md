## Description

Craig Roy (Northcoast Helicopters) is currently using Ciro for flight duty logging and wants to explore a custom-built alternative. He has ~5 aircraft and several pilots across multiple locations.

**Required Features**

- Log pilot duty time (time on duty)
- Log pilot flight time (time in aircraft)
- Manual data entry only — no tracker integration needed
- Records stored on file for CTA audit purposes (no external data push required)
- Offline functionality with sync when internet is available

**Out of Scope**

- Automatic logging via tracking devices
- Integration with SpiderTracks or any third-party tracker
- Invoicing or scheduling features

**Notes**

- Simplicity is the priority — a bare-bones app that gets the job done
- Craig can provide his Ciro login for reference and CTA regulations for compliance requirements
