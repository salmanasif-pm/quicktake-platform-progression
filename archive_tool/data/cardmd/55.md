## Description

**Client Pain Point:**
Sam, an ESL teacher, built basic AI tools using ChatGPT, but they aren't scalable or monetized. He can’t fine-tune models for CEFR levels (A1, A2, etc), lacks user authentication, payment control, and users can’t save or reuse generated content.

**Problem Statement:**
Current tools are free, static, and not level-controlled. Sam needs a scalable, paid platform with fine-tuned AI, teacher-focused tools, and proper access management to turn his idea into a real business.

**Work to Be Done (MVP):**

- Fine-tuned AI for A1-level English content
- Simple web UI with CEFR level selection
- Chat-style interface for input/output
- Stripe subscription setup (free tier + paid)
- Basic user login & access control
- Scalable backend for adding A2/B1 later
