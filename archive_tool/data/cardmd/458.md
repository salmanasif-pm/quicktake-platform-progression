### Brief Solution Overview

Shoreline wants to explore an **AI-powered document review and workflow solution for its credit union operations**.

The primary use case is **loan file review**. Today, an employee manually reviews roughly **50–60 consumer loan packets per month**, with vehicle loans being the main focus. The solution should analyze PDF loan packets for missing documents/pages, unchecked boxes, signatures, initials, dates, incorrect or inconsistent information, and other checklist/policy issues.

There is also a **DTI validation use case**, where the system should pull relevant debts from the credit report and compare them against standardized income information to identify calculation errors or threshold issues.

Findings should be presented to a human reviewer with the relevant document/page/field and then routed back to the **loan officer** for correction. Final loan acceptance, policy exceptions, and credit decisions remain human-controlled.

A secondary use case is **Accounts Payable automation**, covering approximately **100–150 invoices/month**. The system would extract invoice information, validate it, flag duplicates/errors, suggest coding, and route invoices for approval.

Their core/accounting platform is **Jack Henry Symitar**, with API integrations potentially required.

Shoreline is currently evaluating **build vs. buy**, so the immediate goal is to give them a clear picture of what a PureLogics-built solution would look like and how we would approach the POC.
