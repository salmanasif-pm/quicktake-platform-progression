## Description

**Michael Georgiou | Beacon Medical Services / Podiatry Billing**

**Background** Podiatry billing company with 35 years of experience. Currently not at capacity in podiatry but planning to expand into new specialisms (vascular, orthopedics) under a new brand, Beacon Medical Services. Billers are paid a percentage of collections so any tool cost needs to be offset by increased throughput.

**Proposal Required - MVP Scope** Team to build a proposal covering the following:

- ModMed integration as starting EHR
- Denial code analyzer with pattern recognition
- CPT/ICD code suggestions from clinical notes
- Pre-submission claim scrubbing and auto-correction (price both with and without)
- Appeal letter generation
- Denial workflow automation
- Chart audits
- Simple dashboard with denial patterns and resolution suggestions
- Success metrics: 30% reduction in denial resolution time, 50 to 100 claims processed, feedback from 2 to 3 billers

**Action for Team: Build a categorical roadmap for Phase 1 (MVP) only covering the above scope, to be included in the proposal.**
