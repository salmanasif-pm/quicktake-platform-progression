## Description

The client, requires a migration of their existing C++ application to a Swift platform, specifically focusing on a tool called Itr (Image Triage and Report). This tool is intended for forensic investigators to quickly image suspect devices, utilizing open-source plugins to collect data and generate reports. The application must support macOS versions 13, 14, and 15, and be capable of executing multiple plugins in a serial manner, with a potential for parallel execution in the future. Additionally, the client emphasizes the importance of a user-friendly interface, as outlined in the Figma diagrams, which detail the look and feel of the application. The project also involves ensuring compatibility with industry-standard document formats and managing the output data effectively.
