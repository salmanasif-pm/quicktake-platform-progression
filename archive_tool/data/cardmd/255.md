## Description

A prospect is looking to develop a **mobile application** using the **Ionic framework** to extend our existing **web-based property management platform**. The app will allow **Property Managers** to create and manage **properties, leases, and invoices**, send **automated payment reminders**, and receive **online payments** via **MyFatura**. **Tenants** will be able to **view invoices, make payments, and submit maintenance requests**. The app will include **role-based access control**, allowing **team members** to assist in property management. Future enhancements will introduce a **subscription module** for premium features and a **tenant rewards system**. Our goal is to ensure **seamless sync between web and mobile**, optimizing performance and user experience.
