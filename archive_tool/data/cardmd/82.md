## Description

Steve, the application creator, is a former law enforcement officer who investigated many child exploitation cases. The goal of the application is to provide a tool for civilians to scan their own computers and devices for potential child abuse material (CSAM), in order to increase reporting to law enforcement.

The key features of the application are:

- It uses a database of over 4 million CSAM hashes to scan local files and drives for potential matches.
- It has a "quick scan" mode that targets common file locations, as well as a full system scan option.
- It does not display any actual CSAM images, but provides a report with file paths if a match is found.
- The user can then choose to report the findings to law enforcement.
- The application is designed to run portably from a USB drive and automatically uninstall itself after use, to avoid detection.
