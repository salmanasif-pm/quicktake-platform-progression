## Description

**Objective:**
The goal of this project is to build a functional MVP for _ABA Recruit_, a web-based staffing platform designed specifically for the ABA therapy industry. This MVP will demonstrate how healthcare providers (clinics, schools, in-home services) can quickly post shift needs for Registered Behavior Technicians (RBTs) and Board Certified Behavior Analysts (BCBAs), and how therapists can browse and apply to those shifts based on availability, location, and experience. The platform will simulate AI-powered matching through rule-based logic and provide simple dashboards for both therapists and providers, along with a basic admin panel. The entire MVP can be developed keeping architecture lightweight and developer-friendly for a junior engineering team. The focus is not on scaling or security at this stage but on proving out the user flows and functionality needed to support investor demos and early user testing—all within a **400-hour time budget.**
