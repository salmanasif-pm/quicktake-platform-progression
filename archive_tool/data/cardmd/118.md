## Description

Build a POC AI lead scoring agent that pulls leads from Apollo, enriches them by scraping LinkedIn, company websites, news, careers pages, and public sources like EEOC, then runs an AI layer to score each lead 0-100 based on custom HR-specific triggers (new CHRO hires, workplace misconduct news, state compliance changes, headcount growth, etc.). Output should include a full reasoning trail per lead, not just a score. Stack: Clay for enrichment, [http://Make.com](http://Make.com "smartCard-inline")  for automation, Apollo as data source, with final output feeding into Salesforce/HubSpot.
