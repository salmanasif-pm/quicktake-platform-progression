## Description

**Description:**

**Phase 1: Medical chart summarization**

- Ingest large PDF medical records (digital, primarily Epic/MyChart format)
- Extract relevant fields only: surgeries, hospital stays, blood transfusions, PT/OT visits, procedures, dates, provider names
- Output structured summaries in client's specific language and format
- Rewrite records from first-person clinical notes to third-person summaries
- Summary length scales with record volume, not a fixed page count
- Human review/approval step before final output is generated
- OCR component (TBD) for handwritten notes via AWS Textract, quote with and without
- Pull pricing data from existing client data sheets
- Integrate pricing output directly into the summarization system

**Technical requirements:**

- HIPAA compliant
- Closed AI system (no data leakage to public models)
- Hallucination safeguards
- PDF ingestion via Dropbox/ShareFile
- Trained on client-provided de-identified sample summaries (15 to 30 examples pending)
