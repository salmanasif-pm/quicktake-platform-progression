## Description

**Raincheck (Mina's AI Investment Tool)**

Mina has an existing AI tool called Raincheck that analyzes investment opportunities. A user pastes a URL from a crowdfunding platform and the tool generates a report with a score based on her company's proprietary framework. She's looking for PureLogics to take it over and improve it before a beta launch.

Main issues to fix:

Reports are taking up to 17 minutes to generate. The tool is not mobile responsive. The current LLM being used is Manus which is now a risk since its founders were put under house arrest in China after Meta acquired it, so we need to replace it likely with Claude.

What we need from Mina before we can start:

Access to the GitHub repo, backend architecture details, information on the tools used (Lovable, Supabase etc), the prompts used to build the framework, a dummy Stripe account so we can test the tool ourselves, and any documentation on how the codebase currently works.
