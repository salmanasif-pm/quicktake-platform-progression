## Description

**Idea:** Ashley is looking for a Print on Demand feature on her website that is Connected to **Printify**. The users can purchase/mint NFTs and the platform will have some Plain Product mockups which can be Customised by the user on the website.

She has a Wordpress based website where she has integrated all the NFT related plugins to sell NFTs, website is ([NFTY Designs](https://www.niftydesigns.io/ "‌")).

The website is also connected with **Printify** already from where the customized product will be routed to the Supplier, gets printed and delivered to the customer.

**Customer Need:** Is to develop the Customization feature on the website and once the customisation is done, it should be forwarded to Printify for order fulfillment.
