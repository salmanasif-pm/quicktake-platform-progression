## Description

The client, working in the raw materials sector, requires a custom software solution to streamline data analysis related to raw material consumption, specifications, pricing, and vendor management. The goal is to improve the efficiency of analyzing raw material invoices, managing supplier data, and comparing material specifications. The software should handle various types of raw materials (minerals, oils, assets, paints) with flexible categorization and automated processing.
