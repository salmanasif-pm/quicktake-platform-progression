## Description

Develop an **AI-powered chatbot with automation** to streamline field reporting, employee queries, and communication. The chatbot should allow workers to **send job photos, use geo-tagging, and receive automated follow-ups**. It must **integrate with TrackVIA** to pull/update data and assist with **HR tasks (PTO, job details, inventory, safety reports)**. The solution should support **text and voice input (English & Spanish)**, be **mobile-friendly**, and have **secure access controls**. Start with **TrackVIA API review**, and ensure **smooth data exchange** before scaling to a larger team.
