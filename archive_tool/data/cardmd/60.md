## Description

MVP Features:

- Allow South African candidates to create profiles and enter their work experience, skills, education, etc. (no CVs)
- Provide a simple, engaging interface for candidates to input their data (e.g. using AI-powered conversational prompts)
- Enable employers/recruiters to post job openings and set criteria for candidate matching
- Implement an algorithm to match candidate profiles to job openings based on the specified criteria
- Allow employers to request cover letters from top matched candidates
- Provide a dashboard for employers to review matched candidates and invite them to apply
- Implement a feedback loop to track application outcomes (hired/not hired)
- Send periodic updates to candidates on the status of their profile

Technical Requirements:

- Develop a web-based platform with an intuitive, modern UI/UX
- Integrate AI-powered conversational interfaces for candidate data input
- Build a robust matching algorithm to pair candidates to jobs
- Implement secure user authentication and data management
- Integrate with external job boards (e.g. LinkedIn, Indeed) to fetch job postings
- Develop employer and candidate dashboards with relevant analytics
- Ensure data privacy and compliance with relevant regulations
