## Description

Client wants to build a platform for ACO management teams to track patient data, reduce costs, and improve outcomes (not for doctors). It will pull data from Medicare claims, hospitals, labs, and EHRs, and combine it into one view per patient. Key features include: data pipelines, a Master Patient Index, analytics (risk scores, cost breakdowns), and dashboards (using Tableau or similar). It must be secure, scalable for more ACOs by 2026, and support role-based access. We need input on existing data feeds, MPI, KPIs, users, and their approval/budget process.
