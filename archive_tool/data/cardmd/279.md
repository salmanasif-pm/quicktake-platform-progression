## Description

The prospect is looking for Standalone Android app to alert technicians when critical SMS messages arrive. Monitors SMS in real time, detects up to 3 user-defined keywords, and triggers a loud, bypassing alarm that overrides silent/DND/sleep modes—even if the phone is locked. Includes a basic UI for keyword management, permission handling, and toggling alerts on/off. Designed for field use where missing urgent alerts isn’t an option.
