## Description

The project involves designing and developing a hosted financial system with a mobile app and backend services for housing communities. Key deliverables include UI/UX design (wireframes, mockups), user-friendly interface development, push notifications for agency news, text messaging capabilities (corporate-wide, property-specific, individual), automated messaging, and integration with the kiosk system for appointment scheduling. The system will integrate [http://Socket.io](http://Socket.io "smartCard-inline")  for real-time chat, Firebase for notifications, Bcrypt for secure authentication, Azure VM with MySQL for database handling, and the Weather Map API for weather-related push notifications. Additionally, robust reporting capabilities, ADA/HIPAA compliance, and comprehensive documentation (code, APIs, deployment) and source code will be provided.
