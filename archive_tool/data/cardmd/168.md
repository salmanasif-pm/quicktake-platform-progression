## **Project Requirements Document – Highland Cabinetry Inc. (Secondary E-Commerce Website)**

_Muhammad Umair Naseem - was with me on this call - so please loop him in solution prep as well._

### **Goal**

- Create a public-facing online store for cabinetry products with advanced e-commerce features and strong SEO performance.

---

### **Reference Websites**

1. [**buywholesalecabinetry.com**](https://buywholesalecabinets.com/?srsltid=AfmBOoo4-M1f5u4EfGyWoQszFaV0sKxCdS96oQyfkQi01J2N1FMcNtBv "‌")
2. [**primecabinetry.com**](https://www.primecabinetry.com/?srsltid=AfmBOoplI1eoUtJfkURwpyzbKrd_entVrjaIXn1bM-TWbgwdTVn186GB "‌")

These websites should serve as **functional and design references**.

> James stated: “I want to base mine off of theirs with all the functionality, arguably better if possible.”

---

### **Core Functional Requirements**

#### **1. Product Catalog**

- Approximately **275 parent SKUs**.
- A few **thousand sub-SKUs** under them (e.g., same cabinet in multiple colors).
- Example: One base 18-inch cabinet available in blue, black, white, gray.
- System must support hierarchical product structure (Parent SKU → Variants).

#### **2. E-Commerce Workflow**

- Customers should be able to **browse, select, and purchase** cabinetry directly.
- Website should be **user-friendly** and **simple to navigate**.
- The site must be designed to **handle high traffic and large transaction volumes** (e.g., 100–200 orders per day).

#### **3. 3D Rendering / Design Tool**

- For **homeowners and do-it-yourselfers**.
- Users should be able to **input measurements** (e.g., 10ft x 5ft kitchen).
- Tool should **visualize the kitchen layout** using selected cabinets.
- Should **suggest designs or layouts** automatically based on input dimensions.
- The goal is to allow users to “see” their kitchen virtually.

#### **4. Portals and Roles**

- **Customer Portal:**
  - Register/log in.
  - Customize their kitchen.
  - View and manage orders.
  - Use 3D rendering tools.
- **Admin Portal:**
  - Manage customers, products, and SKUs.
  - Monitor website activity (e.g., traffic, top-used SKUs).
  - Handle business analytics.
- **User Roles:**
  - Approximately **5–10 different roles** expected, including:
    - Admin
    - Customer
    - Vendor (limited access)
    - Freight specialist
    - IT staff
    - SEO specialist
  - (James clarified he was referring to _types of users_, not user count.)

#### **5. Vendor Management**

- Vendors will **not** have control or management privileges on the website.
- Vendor data should sync via **ERP integration**:
  - Either through an **API connection** to the ERP (preferred).
  - Or via **daily inventory file uploads**.
- No separate vendor portal for operations.
- Optional (low priority): potential vendor **portfolio feature** (for future), where vendors could showcase previous work, but James marked this as _low priority_.

#### **6. ERP Integration**

- The website must connect with backend **ERP systems** to:
  - Retrieve **inventory and stock levels**.
  - Support **multi-vendor** data (if required in the future).
- Integration method: **API or file-based sync**.

#### **7. Technology & Platform**

- Current Highland website is on **WordPress**, but the new one may use a different stack.
- **No fixed technology preference** stated by the client.
- Open to recommendations for both:
  - **Platform/framework choice**, and
  - **Plugins/tools** for specific functions (e.g., 3D rendering).
- **Key requirement:** Must be _highly scalable, stable under high traffic_, and _user-friendly_.
- **Performance expectations:**
  - Load balancing should be implemented.
  - System should not crash under heavy concurrent usage.
- **AI Integration:**
  - Team member (Muhammad) suggested possible use of **Python and AI** for 3D rendering/customization.
  - James did **not** request AI specifically but was open to efficient technical solutions.

#### **8. SEO & Marketing**

- **Very high priority.**
- Website must be designed for **strong SEO performance**.
- Full **flexibility and control over SEO elements** (meta tags, URLs, schema, etc.).
- Must allow integration with marketing and analytics tools.
- Client runs an SEO company and plans to manage optimization internally.
- Client emphasized: “That’s my hesitation with Shopify — I want to make sure I can fully control SEO.”

---

### **9. Design Expectations**

- Must be **beautiful and modern**.
- **User-friendly interface** and **easy navigation** are critical.
- Should visually compete with or surpass the reference sites.

---

### **10. Traffic and Load Expectations**

- High-volume site expected (100–200 orders per day).
- Must support **heavy concurrent traffic** without degradation.
- Load balancing and performance optimization are required.

---
